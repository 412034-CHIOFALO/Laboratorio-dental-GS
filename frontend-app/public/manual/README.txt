Capturas del manual de usuario
================================

Guardá cada captura acá como PNG con EXACTAMENTE el nombre del id indicado.
Al dejar el archivo, el manual la muestra sola (reemplaza el placeholder).
Si el archivo no existe, queda el recuadro "Captura pendiente".

Ruta pública: /manual/<id>.png

Capturas esperadas (id → qué mostrar):

  cap-inicio          → Pantalla de Inicio: tarjetas de resumen + accesos rápidos.
  cap-pedidos-lista   → Tabla de Pedidos con un atrasado y uno "sin precio" visibles.
  cap-produccion      → Tablero Kanban con tarjetas en varias columnas.
  cap-entregas-modal  → Modal de entrega con el campo "Monto a facturar".
  cap-catalogo        → Grilla del catálogo de trabajos.
  cap-stock           → Lista de materiales con uno en Bajo/Crítico.
  cap-finanzas        → Dashboard de finanzas: 3 cajas + ranking de morosos.
  cap-cuenta-corriente→ Ficha del odontólogo: sección Cuenta corriente + botón "Registrar pago".
  cap-bot             → Estado del bot (QR o "conectado") y/o registros.
  cap-visor-3d        → Visor 3D abierto con un modelo.
  cap-reportes        → Pantalla de reportes con los indicadores.
  cap-mi-perfil       → Pantalla Mi perfil (datos + cambio de contraseña).

Recomendado: capturas en tema claro, ~1200px de ancho, recortadas al área útil.
